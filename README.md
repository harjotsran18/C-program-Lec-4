# C Program - Lec 4

Semester II - C Programming practice exercises and lecture examples.

## Topics Covered
- Decision Making and Conditional Statements (`if`, `if-else`, `else-if` ladder)
- Boundary condition checks and threshold comparisons
- Tiered slab rate calculation (Electricity bill)

## Programs

- **`pass.c`**: Check whether a student has passed or failed based on marks and passing criteria
- **`shape.c`**: Determine if a shape is a square or rectangle by comparing length and breadth
- **`speed.c`**: Vehicle speed monitor to check against road speed limit
- **`unit.c`**: Electricity bill calculator with tiered unit slabs

## How to Compile and Run

Using MinGW / GCC:

```bash
gcc filename.c -o filename.exe
./filename.exe
```
